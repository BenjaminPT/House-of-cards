## Установка

| Платформа | Как получить |
| --- | --- |
| **Любая (PWA)** | Откройте [сайт](https://benjaminpt.github.io/house-of-cards/) и нажмите «Установить» (Chrome/Edge/Android) или «Поделиться → На экран Домой» (iPhone/iPad). Работает офлайн. |
| **Windows** | Скачайте `House-of-Cards-Setup-win-x64.exe`, запустите установщик. |
| **macOS** | Скачайте `.dmg` (Apple Silicon — `arm64`, Intel — `x64`), перетащите приложение в «Программы». |

> Сборки не подписаны платным сертификатом, поэтому системы предупреждают при первом запуске.  
> **Windows:** «Подробнее» → «Выполнить в любом случае».  
> **macOS:** правый клик по приложению → «Открыть». Если macOS пишет «повреждено», выполните в Терминале:  
> `xattr -cr "/Applications/House of Cards.app"`

## Игры

| Игра | Игроков | Что внутри |
| --- | --- | --- |
| **Покер** | 2–6 | Техасский холдем, турнир с растущими блайндами, фолд/чек/колл/рейз/олл-ин, сайд-поты, боты на основе Монте-Карло-оценки руки. |
| **21** | 1–5 | Блэкджек: ставки, удвоение, сплит (до 4 рук), блэкджек 3:2, дилер добирает до 17, боты по базовой стратегии. |
| **Пасьянс** | 1–4 | Косынка (1 или 3 карты): перетаскивание и тап-для-хода, отмена, подсказка, автосбор. Онлайн — дуэль на одной раздаче. |
| **Сиквенс** | 2–4 | Поле 10×10, двойные и одноглазые валеты, мёртвые карты, команды 2×2, подсветка ходов. |
| **Рулетка** | 1–6 | Европейская (один ноль), все виды ставок (число, сплит, угол, стрит, шестёрка, дюжины, колонки, шансы), анимированное колесо. |

Играть можно с ботами или онлайн. Фишки виртуальные.

## Рубашки карт

Кнопка с картами в шапке открывает редактор:

- 10 узоров + градиент + **своё фото** (сжимается и хранится локально);
- два цвета, эмблема (масти, корона, звезда, **монограмма**), рамка;
- 8 готовых тем, генератор случайной рубашки, 3 слота для сохранения;
- предпросмотр с наклоном и переворотом.

Онлайн соперники **видят вашу рубашку** на ваших закрытых картах.

## Онлайн

Выберите игру → «Онлайн-комната» (или кнопка с глобусом). Вы получаете 5-символьный код и ссылку, друзья вводят код или открывают ссылку. Хост выбирает игру и может добавить ботов.

- Соединение **напрямую между игроками (WebRTC)**, регистрация и свой сервер не нужны; для знакомства пиров используется публичный сервер сигналов PeerJS.
- Игрой управляет хост: карты колоды и закрытые карты соперников к гостям **не отправляются**.
- Вышедшего игрока заменяет бот, переподключиться можно по тому же коду. На ход в онлайне даётся 45 секунд.
- У пары игроков за строгим NAT/VPN прямое соединение может не установиться — попробуйте другую сеть (TURN-сервера в проекте нет).

## Горячие клавиши

`H` ещё · `S` хватит · `D` удвоить · `P` сплит (21) — `F` фолд · `C` чек/колл · `R` рейз (покер) — `U` отмена · `H` подсказка · `A` автосбор (пасьянс) — `1–5` фишка · `Z` отмена ставки (рулетка).

## Разработка

```bash
npm install          # ставит Electron, electron-builder и копирует PeerJS в js/vendor
npm run serve        # PWA на http://localhost:8080
npm start            # десктопная версия (Electron)
npm test             # симуляции движков: ничего не ломается, фишки сохраняются
npm run dist:win     # установщик Windows (запускать на Windows)
npm run dist:mac     # .dmg (запускать на macOS)
```

Установщики собираются автоматически в **GitHub Actions**: пуш тега `v*` (например `git tag v1.0.1 && git push --tags`) или ручной запуск «Build installers» создаёт релиз с `.exe` и `.dmg`. Сайт (PWA) публикуется на GitHub Pages при каждом пуше в `main`.

### Структура

```
js/engines/   чистая логика игр без DOM (тестируются в Node)
js/games/     интерфейс каждой игры
js/core/      карты и рубашки, анимации (WAAPI + пружины), звук (WebAudio), сессия хоста, WebRTC
electron/     оболочка для Windows/macOS
sw.js         офлайн-кеш PWA
```

Один и тот же движок работает и офлайн с ботами, и онлайн: хост ведёт состояние, гости отправляют действия и получают персональные «срезы» состояния.
